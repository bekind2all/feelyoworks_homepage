# Feelyoworks robots policy
# Goal: maximize discoverability in both classic search and AI answer engines (GEO).
#
# Policy summary:
#   - Search indexing: allowed for all major engines.
#   - AI retrieval / grounding (RAG, AI search answers): allowed — this is how
#     Feelyoworks gets cited when someone asks an AI for an AI 교육 강사.
#   - Model training: opted out via Content-Signal (ai-train=no), which is a
#     rights reservation, not a crawl block. Crawling stays allowed so the site
#     remains citable.
#
# NOTE: Cloudflare may prepend a "Managed Content" block to the served robots.txt
# that disallows ClaudeBot, CCBot, GPTBot, Google-Extended, Applebot-Extended,
# meta-externalagent, Amazonbot and Bytespider. That block is injected at the
# edge and CANNOT be overridden from this file. It must be disabled in the
# Cloudflare dashboard (AI Crawl Control / Manage robots.txt).
# See GEO_ACTION_PLAN.md → "Cloudflare 대시보드 조치".

User-agent: *
Content-Signal: search=yes,ai-input=yes,ai-train=no
