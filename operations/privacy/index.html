처리 목적과 정보

앱은 강의 의뢰 접수, 고객·기관 관리, 일정과 준비 업무 관리, 교안·강의 기록 연결, 청구·입금 확인 및 업무 이력 보존에 필요한 정보를 처리합니다. 관리자가 입력하거나 연결한 범위에서 담당자 이름·기관·이메일·연락처, 의뢰·통화 기록, 일정, 메일 본문·첨부, 계약·청구·입금 자료 및 문서 링크를 저장합니다. Google Calendar 연결만으로 Gmail이나 Google Drive에 접근하지 않습니다.

Google Calendar 접근·이용

Google의 동의 화면에서 권한을 승인한 계정에 한해 캘린더 목록·이름·식별자·색상·접근 권한과 선택한 캘린더의 일정 식별자·제목·설명·시작 및 종료 시각·장소·원문 링크·상태를 읽습니다. Google API 응답에는 참석자 등 부가 항목이 포함될 수 있으나 자동 동기화는 위 업무 항목을 선별하여 저장합니다. 이 정보는 일정 표시, 변경·취소 반영, 강의·메일·기록·교안과의 연결에 이용합니다. 앱은 캘린더 목록 읽기 권한과 일정 접근 권한을 요청합니다. 자동 동기화는 Google 원본을 변경하지 않습니다. 앱에서 작성·수정 내용을 확인하고 사용자가 명시적으로 반영한 경우에만 선택한 캘린더의 일정을 생성·수정합니다. 초대 발송이나 원본 일정 삭제를 자동 실행하지 않습니다.

저장과 보호

업무 자료는 운영자가 사용하는 PC의 앱 데이터베이스·첨부 저장소에 보관합니다. 로그인과 역할에 따른 접근 제한, 변경 감사 기록을 적용합니다. OAuth 갱신 토큰, 네이버 앱 비밀번호와 백업 암호는 1Password의 지정 금고에 보관하고 필요한 실행 중에만 읽습니다. Google·네이버와의 외부 통신은 암호화된 연결을 사용합니다. 백업은 이 PC에 암호화하여 저장하며 복원 검증 중 별도의 로컬 복원본이 생성될 수 있습니다. 운영 DB 전체가 암호화되어 있다는 의미는 아닙니다. PC·금고에 접근할 수 있는 계정을 관리하고 승인되지 않은 접근을 제한합니다.

외부 서비스와 제공 범위

Google은 OAuth 인증과 Calendar API 제공에, 네이버는 승인된 메일 수신에, 1Password는 암호·토큰 보관에 사용됩니다. Notion·Canva·Drive 자료는 관리자가 연결한 문서와 업무 자산을 참조하는 데 사용합니다. 공개 안내 페이지에는 앱의 비공개 메일·일정·거래 원문을 게시하지 않습니다. 별도로 승인된 MCP 읽기 도구를 사용하면 권한 범위 내의 업무 조회 결과가 해당 AI 도구로 전달될 수 있으며, 이 경우 해당 서비스의 이용·개인정보 정책도 적용됩니다. 자동 캘린더 동기화 자체는 일정 원문을 외부 AI에 전송하지 않습니다. 업무 자료를 판매하거나 광고 타기팅·일반 목적 AI 모델 학습에 이용하지 않습니다.

보유·삭제와 연결 해제

업무 수행과 이력 확인에 필요한 동안 자료를 보관하며, 목적 달성 또는 정당한 삭제 요청 시 관리자가 해당 자료와 관련 사본을 확인하여 삭제 또는 비식별 처리합니다. 법적 의무나 분쟁 대응 때문에 보관이 필요한 경우에는 해당 근거와 범위를 확인하여 필요한 자료만 별도 관리합니다. 백업과 복원 검증 사본에도 자료가 남을 수 있으므로 삭제 처리 시 함께 확인합니다. 현재 자동 보존기간 만료·일괄 삭제 기능은 운영하지 않습니다. Google 계정의 연결된 앱 관리에서 권한을 철회하면 추가 API 접근이 중단됩니다. 권한 철회나 캘린더 선택 해제는 이미 저장된 업무 기록을 자동 삭제하지 않습니다. 저장 자료·토큰 삭제는 위 문의 주소로 요청할 수 있습니다.
